# 开发 Timeline

`timeline/` 保存项目开发轨迹。每次提交代码、修改界面、增加功能、调整配置或更新工程规范后，都必须在当天的 `YYYY-MM-DD.md` 文件末尾追加一条记录；当天文件不存在时新建。

## 条目格式

```md
## HH:MM CST - 简短范围

- 改动：做了什么，行为如何变化。
- 新增：新增的功能、文件、依赖或文档；没有则写“无”。
- 影响：涉及的模块或用户可见界面。
- 安全：文件、子进程、网络、模型下载或用户数据的影响；没有则写“无新增安全影响”。
- 验证：实际执行的命令和结果；未执行时说明原因。
- 后续：尚未完成的工作；没有则写“无”。
```

时间使用开发完成时的本地时间，并保留时区缩写。记录事实，不补写无法确认的历史时间，不虚构功能、依赖、接口或验证结果。
